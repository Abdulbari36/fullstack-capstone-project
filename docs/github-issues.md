## How to recreate this in your repo (for the screenshot)

1. Push this project to GitHub as **fullstack-capstone-project** (public repo).
2. Go to **Issues → New issue** and create each user story above (title = the US#, body = the story from `docs/user-story.md`).
3. Create the four labels: `new`, `icebox`, `technical debt`, `backlog`
   (Issues → Labels → New label), and attach them as listed.
4. Open the **Issues** tab so the repo name and ≥8 labeled issues are visible.
5. Take a full-window screenshot and save it as **userstories.png** in `docs/`.
